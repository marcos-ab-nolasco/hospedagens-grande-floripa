# Floripa, pertinho

Guia estático de hospedagens para convidados, feito em HTML, CSS e JavaScript sem dependências de build. Para publicar no GitHub Pages, envie estes arquivos ao repositório e selecione a branch e a pasta raiz nas configurações de Pages.

## Referências de pesquisa

Pesquisa realizada em 30/09/2026. Tarifas são snapshots encontrados online, geralmente de uma noite para duas pessoas em datas próximas; a faixa para estadia longa é uma estimativa simples de planejamento, sem taxas e sem garantia de disponibilidade de 25/10 a 05/11/2026.

- [AZZA Smart Stay — Decolar](https://www.decolar.com/hoteis/h-6205632/azza-smart-stay-florianopolis): R$ 212/noite observado para 27/09/2026; localização a cerca de 700 m da UFSC segundo Hoteis.com.
- [Quinta da Bica d’Água — KAYAK](https://www.kayak.com.br/Hoteis-Hotel-Quinta-Da-Bica-Da-Agua-Florianopolis.450394.ksp): ofertas recentes a partir de R$ 207/noite; localização próxima à UFSC.
- [Interclass — Decolar](https://www.decolar.com/hoteis/h-204973/interclass-florianopolis-florianopolis) e [reserva oficial](https://book.omnibees.com/chain/7864/hotel/13424?errredir=1): tarifas observadas em consultas recentes entre R$ 356 e R$ 412/noite; hotel ao lado da UFSC.
- [Mercure Florianópolis — Accor](https://all.accor.com/hotel/5693/index.pt-br.shtml): referência de tarifa especial 2026 para quarto duplo standard de R$ 389 em acordo tarifário consultado.
- [Kennedy Executive — KAYAK](https://www.kayak.com.br/Hoteis-Kennedy-Executive-Hotel-Sao-Jose.725926.ksp): a partir de R$ 322/noite; média recente informada de R$ 387.
- [K-Platz — Expedia](https://www.expedia.com.br/Florianopolis-Hoteis-K-PLATZ-HOTEL.h68569482.Hotel-Reservas): R$ 415 observado; [site oficial de reservas](https://book.omnibees.com/chain/7242/hotel/13440?currencyId=109&lang=pt-BR&q=13440) indicou tarifas desde R$ 528.
- [Hotel São José — site oficial](https://www.saojosehotel.com.br/): preço deve ser consultado diretamente.
- [Airbnb perto da UFSC](https://www.airbnb.com/ufsc-florianopolis-brazil/stays/apartments): referência para anúncios como studios em Trindade, Pantanal e entorno. As faixas exibidas para apartamentos são estimativas de planejamento, não preços publicados para as datas do casamento.
- [Airbnb Santo Antônio de Lisboa](https://www.airbnb.com/s/Santo-Ant%C3%B4nio-de-Lisboa--Florian%C3%B3polis--Brazil/homes) e [Campeche](https://www.airbnb.com/s/Campeche--Florian%C3%B3polis--Brazil/homes): páginas de busca; estimativas variam bastante por imóvel e configuração.

Distâncias aproximadas por região, não por rota precisa. Imagens genéricas são ilustrativas; imagens identificadas como fotos da hospedagem vêm das páginas ligadas no respectivo cartão.
