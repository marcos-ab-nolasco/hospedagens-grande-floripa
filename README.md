# Floripa, pertinho

Guia estático de hospedagens para convidados, feito em HTML, CSS e JavaScript sem dependências de build. Para publicar no GitHub Pages, envie estes arquivos ao repositório e selecione a branch e a pasta raiz nas configurações de Pages.

Distâncias e tempos em carro são aproximados e podem variar com o ponto de partida e trânsito. As imagens dos novos hotéis e pousadas são fotos publicadas em páginas das próprias hospedagens ou de parceiros de reserva; imagens de apartamentos e demais cartões podem ser ilustrativas. O guia reúne até 15 sugestões, priorizando bairros que combinam com a região da UFSC e opções citadas pelo casal.
